# PlayTogether

A tiny hub of two-player browser games you can play live with a friend in another home.
It needs no server and no accounts. The browsers connect directly.

**Play:** https://ythereal.github.io/playtogether/

## How to play

1. Open a game and click **Host a game**.
2. Send your friend the invite link (or the 4-letter code).
3. They open it, and you're connected.

If either of you reloads (for example after an update), you rejoin the same room automatically.

## One-time setup (GitHub Pages)

Repo → **Settings → Pages** → Source: *Deploy from a branch* → `main` / `(root)` → Save.

## Adding or changing games

Ask Claude Code. The conventions it follows are in [`CLAUDE.md`](CLAUDE.md).
Every push to `main` goes live in about a minute.
